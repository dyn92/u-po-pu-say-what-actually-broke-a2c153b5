Entry for the make.fun bounty [Say What Actually Broke](https://make.fun/c/u-po-pu-say-what-actually-broke-a2c153b5): one line of software error copy that tells the user the brutal truth about what went wrong and makes them laugh.

`main.py` (pure Python standard library) writes the line to `/output/entry.txt`:

> The server ran out of memory and dropped your request like a hot potato. Nothing was saved, please try again in a moment.

Run it with:

```sh
python3 main.py
```
